# せどり収支管理アプリ

仕入れ値・送料・手数料・売値を入力すると、純利益や利益率を自動計算して管理できるWebアプリです。
データはクラウドのデータベース（Turso）に保存されるため、一度入力した内容は消えません。
デプロイ後はスマホのモバイルデータ通信からも、発行されたURLでどこからでもアクセスできます。

## できること

- 商品ごとに 仕入れ値・送料・手数料・その他経費・売値 を記録し、利益を自動計算
- 未売却／売却済みのステータス管理（在庫管理）
- 商品名・カテゴリ・仕入れ先での検索
- 月次の売上・利益推移グラフ
- カテゴリ別の件数グラフ
- 総売上・総経費・純利益・利益率・在庫件数のサマリー表示

## 技術構成

- フレームワーク: Next.js（フロントエンド＋API を1つのアプリで完結）
- データベース: [Turso](https://turso.tech)（SQLite互換のクラウドDB、無料枠あり、データは自動的に永続化）
- ホスティング: [Vercel](https://vercel.com)（無料枠あり、Gitリポジトリを連携するだけで公開URLが発行される）

この組み合わせなら、月額0円〜で「スマホのモバイル回線からアクセスできる」「データが消えない」を両立できます。

## デプロイ手順（初回のみ）

### 1. Turso（データベース）を用意する

1. https://turso.tech にアクセスし、アカウントを作成（GitHubアカウントでログイン可能）
2. ダッシュボードで「Create Database」を選択し、データベースを作成（名前は自由。例: `sedori-db`）
3. 作成後、データベースの詳細画面で以下の2つを控える
   - **Database URL**（`libsql://xxxxx.turso.io` の形式）
   - **Auth Token**（「Create Token」ボタンなどから発行）

### 2. コードをGitHubにアップロードする

1. GitHubでアカウントを作成（すでにあれば不要）
2. 新しいリポジトリを作成（例: `sedori-app`）
3. このフォルダ（`sedori-app`）の中身をそのリポジトリにアップロード
   - GitHub Desktop を使う場合: このフォルダを「Add local repository」して Publish するだけでOK
   - コマンドラインの場合:
     ```bash
     cd sedori-app
     git init
     git add .
     git commit -m "初回コミット"
     git branch -M main
     git remote add origin https://github.com/あなたのユーザー名/sedori-app.git
     git push -u origin main
     ```

### 3. Vercelで公開する

1. https://vercel.com にアクセスし、GitHubアカウントでログイン
2. 「Add New」→「Project」から、先ほど作成した `sedori-app` リポジトリを選択
3. 「Environment Variables」の設定画面で、以下の2つを追加
   - `TURSO_DATABASE_URL` = 手順1で控えたDatabase URL
   - `TURSO_AUTH_TOKEN` = 手順1で控えたAuth Token
4. 「Deploy」ボタンを押す（数分で完了）
5. 完了すると `https://sedori-app-xxxx.vercel.app` のようなURLが発行される
   - このURLにスマホからアクセスすれば、モバイルデータ通信でも利用可能
   - URLをスマホのホーム画面に追加すると、アプリのように使えます

以降、データはTursoのデータベースに保存され続けるため、アプリを閉じても・別の端末からアクセスしても、同じデータが表示されます。

## ローカルで動作確認したい場合（任意）

デプロイ前にパソコンで動作を試したい場合は、以下を実行してください（Node.js が必要です）。

```bash
cd sedori-app
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開くと確認できます。
このとき環境変数を設定していなければ、フォルダ内に `local.db` というファイルが自動生成され、そこにデータが保存されます（この場合はパソコン内だけの保存になります）。

Turso接続情報を使ってローカルでも本番と同じデータベースに繋ぎたい場合は、`.env.local.example` を `.env.local` にコピーし、中身をTursoの値に書き換えてください。

## データ項目

| 項目 | 説明 |
|---|---|
| 商品名 | 必須 |
| カテゴリ | 自由入力（例: ゲーム、家電） |
| 仕入れ先 | 自由入力（例: 店舗名、サイト名） |
| 仕入れ値 | 円 |
| 送料 | 円 |
| 販売手数料 | 円 |
| その他経費 | 円 |
| 売値 | 円 |
| ステータス | 未売却 / 売却済み |
| 仕入れ日・売却日 | 日付 |
| メモ | 自由入力 |

利益 = 売値 −（仕入れ値＋送料＋販売手数料＋その他経費）で自動計算されます。
サマリーの「純利益」「総売上」「利益率」は、ステータスが「売却済み」のものだけを集計します。
